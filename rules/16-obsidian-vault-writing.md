# Documentação em vaults

Se o projeto usa Obsidian, consultar o guia de escrita declarado no contexto antes de editar.
Usar nomes Title-Case-Com-Hifen.md, frontmatter e atualização de `updated` em cada edição CLI.
Buscar uma nota existente antes de criar outra. Não assumir que o vault pessoal existe nesta máquina.
