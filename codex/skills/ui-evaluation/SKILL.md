# UI evaluation

Read the current task and project rubric before evaluating. The rubric, form and user
instructions determine the comparison dimensions, evidence and submission process.
Inspect each candidate independently through the project-approved browser tools.
Record concrete observed behavior, including failures and relevant viewport sizes.
Do not reuse customer-specific rubrics, private evaluation history or prior scores.
If the rubric or authorized editable task is unavailable, report the missing input.
Write review notes in Portuguese and requested form answers in English. Distinguish
saved drafts, published answers and independent validation. Follow the current user's
submission authorization rather than assuming that evaluating authorizes publication.
